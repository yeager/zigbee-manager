# Zigbee Manager

Zigbee device manager for smart home networks.

Built with GTK4/Adwaita. Part of the [Danne L10n Suite](https://github.com/yeager/debian-repo).

## Installation

### Debian/Ubuntu
```bash
sudo apt install zigbee-manager
```

### Fedora/RPM
```bash
sudo dnf install zigbee-manager
```
